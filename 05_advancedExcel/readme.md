## Excel Data Validation, Data Cleaning & Sheet Protection

## 📌 Project Overview

This project demonstrates how Microsoft Excel can be used to clean, validate, and secure employee data before analysis. It includes practical features commonly used by Data Analysts in real-world business environments.

# ✅ Features Implemented

## 1. Data Validation

Applied validation rules to improve data quality.

### Department
- Dropdown list
- Prevents invalid department names

Departments:
- IT
- HR
- Sales
- Marketing
- Non-IT
- Others

### Location
Dropdown list with predefined locations.

Locations:
- BNGLR
- Mumbai
- Rajasthan
- Chennai
- HYD

### Salary Validation

Allowed Salary Range:

10000 – 100000

Invalid values are rejected using Excel Data Validation.

### Employee ID Validation

Employee ID must contain

- Minimum: 1 digit
- Maximum: 6 digits

---

# 2. Remove Duplicates

Duplicate Employee IDs were identified and removed using

Data → Remove Duplicates

This ensures every employee has a unique record.

---

# 3. Error Alert

Custom error messages are displayed when users enter invalid values.

Example:

Title:
Invalid Salary

Message:
Salary must be between 10000 and 100000.

---

# 4. Input Message

Helpful input messages guide users while entering data.

Example:

Salary:
Enter a value between 10000 and 100000.

---

# 5. Sheet Protection

Workbook protection has been implemented.

✔ Formula cells are locked

✔ Validation rules are protected

✔ Only input cells are editable

This prevents accidental modification of important formulas and validation settings.
