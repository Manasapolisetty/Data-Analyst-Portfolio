# 📊 Excel Pivot Table Analysis – Day 8

## 📌 Project Overview

This project demonstrates how to analyze employee data using Microsoft Excel Pivot Tables.

The objective is to summarize large datasets without writing formulas and answer common business questions through interactive reports.

This project is part of my **90-Day Data Analyst Placement Bootcamp**.

---

# 🎯 Learning Objectives

- Understand Pivot Tables
- Summarize data efficiently
- Analyze employee information
- Generate business reports
- Build the foundation for Excel Dashboards

---

# 🛠 Tools Used

- Microsoft Excel 2016
- Pivot Tables
- Value Field Settings
- Sorting & Filtering

---

# 📂 Dataset

The dataset contains employee information with the following columns:

- Employee ID
- Name
- Gender
- Department
- City
- Salary
- Experience
- Rating

Total Records: **10**

---

# 📈 Business Questions Solved

### 1. Department-wise Employee Count

Shows the total number of employees in each department.

---

### 2. Department-wise Total Salary

Displays the total salary paid by each department.

---

### 3. Department-wise Average Salary

Calculates the average salary for each department.

---

### 4. City-wise Employee Count

Displays the number of employees working in each city.

---

### 5. Gender-wise Employee Count

Shows the total number of male and female employees.

---

### 6. Department-wise Highest Salary

Finds the highest salary in each department.

---

### 7. Department-wise Lowest Salary

Finds the lowest salary in each department.

---

### 8. Department-wise Average Experience

Calculates the average years of experience.

---

### 9. Department-wise Average Rating

Calculates the average employee rating.

---

### 10. Department vs Gender

Compares the number of male and female employees across departments.

---

### 11. Department vs City

Displays employee distribution by department and city.

---

### 12. Department Summary

Provides:
- Employee Count
- Total Salary
- Average Salary
- Highest Salary
- Lowest Salary
- Average Experience
- Average Rating
