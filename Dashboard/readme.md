# 📊 Employee Analytics Dashboard — Excel

## 📌 Project Overview

This project is an interactive **Employee Analytics Dashboard** created using **Microsoft Excel**.

The dashboard uses Excel Tables, Pivot Tables, Pivot Charts, KPI cards, and Slicers to analyze employee information such as salary, department, city, gender, and employee count.

The main objective of this project is to practice real-world **Data Analyst Excel skills** and create an interactive dashboard for quick business analysis.

---

## 🛠️ Tools Used

- Microsoft Excel 2016
- Excel Tables
- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers
- Conditional Formatting
- Excel Formulas
